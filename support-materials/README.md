The live pages are at https://172checkit.netlify.app/ . Outcomes are added to this table as they are finished.

To download everything at once: on the repo home page click **Code → Download ZIP**.

## What each file is

- `CODE_worked_examples.docx` / `.pdf` — landscape worked-examples document for recording (blank right third for ink)
- `CODE_canvas_quiz.zip` — Canvas quiz. Import the whole .zip unopened: Settings > Import Course Content > QTI .zip file
- `CODE_libretexts_page.html` — LibreTexts page code
- `CODE_audit.md` — accessibility audit notes (where one was written)

Regenerate with `tools/derive.sh CODE` and `python3 tools/canvas-quiz/make_quiz.py CODE`.
